JUANDIPROMPTER 1.1
Antes de actualizar: en la biblioteca de la versión 1.0, pulsa Exportar copia y conserva el JSON.
Para probar en PC: descomprime y abre index.html. Para actualizar GitHub Pages, sube los archivos descomprimidos al MISMO repositorio y rama, reemplazando los existentes. No cambies la URL: los datos locales dependen del origen. Abre la aplicación con internet después de que termine el despliegue; recarga o cierra y vuelve a abrir si aún ves v1.0. No borres datos de Safari ni desinstales la app.
La versión conserva jp-scripts y jp-prefs; agrega preferencias nuevas y posición local por guion. En el lector, pulsa Pantalla completa. En PC usa Escape para salir; en iPhone toca la pantalla para mostrar el botón Mostrar controles. El modo limpio funciona aunque el navegador no admita la API de pantalla completa. Para aprovechar toda la pantalla instala la web desde Safari. Mantener pantalla encendida depende del navegador y el sistema.
Nuevos ajustes: fuente, colores, interlineado, ancho, altura y visibilidad de guía, pantalla encendida. Guardado automático tras 700 ms. El tiempo restante y la posición recuperada son aproximados. Editar el texto reinicia su posición. La app no impone límites de texto; el almacenamiento local tiene cuota y puede fallar. Exporta copias periódicamente.
No se incorporan grabación, sincronización ni seguimiento de voz.
